# Architecture Decision Records (ADR)

ADRs capture significant technical decisions and the reasoning behind them.

## Process
1. Copy `template.md` to a new numbered file.
2. Name files as `NNNN-short-title.md` (example: `0002-api-versioning-strategy.md`).
3. Focus on clear problem framing, decision rationale, and trade-offs.
4. Link related PRs, issues, and architecture documents when relevant.
